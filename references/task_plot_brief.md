# Task Plot Brief

## Task

- Title: Matrix Reasoning
- Construct: abstract reasoning / relational reasoning / fluid intelligence
- Paradigm: 3x3 abstract matrix completion with four answer options.

## Rows

- Practice: three practice items with feedback.
- Easy scored: scored matrix items without feedback.
- Medium scored: scored matrix items without feedback.
- Hard scored: scored matrix items without feedback.

## Trial Timeline

1. Fixation: 500 ms fixation, no response.
2. Blank screen: 100 ms white blank screen.
3. Matrix response open: 25000 ms. Show 3x3 matrix, four answer cards, and prompt. Press 1, 2, 3, or 4.
4. Matrix response warning: final 5000 ms with clock warning if no response yet.
5. Practice feedback: 800 ms practice-only correct, incorrect, or timeout feedback.
6. ITI: 600 ms fixation before next trial.

## Notes

- The bank is three practice items followed by 12 scored items.
- Scored items do not show trial feedback.
- Matrix stimuli are deterministic geometric-rule proxies, not copyrighted matrix-reasoning items.
